# Alyssa Indrajaya — independent GitHub Pages website

All site content, images, blog posts, CV and resume in this package are hosted in this repository. There are no Wix dependencies. The external links to research papers, LinkedIn and the Learning Sciences Laboratory are intentional.

## Upload to GitHub

1. Unzip `alyssa-research-independent-site.zip`.
2. Open your GitHub `research` repository and upload **the contents** of the extracted folder, not the folder itself. Preserve `assets/` and `blog/` directories.
3. Existing `index.html`, `conferences.html`, `styles.css` and `README.md` need to be replaced. GitHub's web uploader may not overwrite existing files: if necessary, delete the old versions first, commit, then upload the replacements. Alternatively, use GitHub Desktop to commit and push the extracted files.
4. In Settings > Pages, deploy from branch `main`, folder `/ (root)`.
5. Visit `https://alyssajindrajaya.github.io/research/` after deployment.

## Edit content

- Homepage: `index.html`
- Conferences: `conferences.html`
- Blog index: `blog.html`
- Article: `blog/on-exams.html`
- Styles: `styles.css`
- Images and downloadable CV/resume: `assets/`
