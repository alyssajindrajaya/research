# Alyssa Indrajaya — Independent research website

This is a FLAT GitHub Pages package: upload ALL files directly into the root of the `research` repository. No folders are needed.

## Clean replacement
1. In GitHub, open the `research` repository's **Code** tab.
2. To avoid breaking the live site while cleaning up, first upload all files in this package via **Add file > Upload files** and commit. If GitHub refuses to overwrite same-named files, use the pencil edit interface for the HTML/CSS files or remove old versions first.
3. Remove obsolete old files only after confirming the new site works.
4. GitHub Pages: Settings > Pages > Deploy from branch > main > /(root).
5. Open https://alyssajindrajaya.github.io/research/ and hard-refresh Ctrl+Shift+R.

All photos, CV, resume, blog and conference pages are local. No Wix assets are used.
