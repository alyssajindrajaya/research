# Alyssa Indrajaya — research website

Static personal academic website, based on the publicly accessible content of the existing Wix website.

## Publish for free using GitHub Pages

1. Sign in to https://github.com and create a new **public** repository named `YOUR-USERNAME.github.io` (replace YOUR-USERNAME with your exact GitHub username).
2. Upload `index.html` and `styles.css` to the repository root (not inside a subfolder). Commit the files.
3. Go to **Settings → Pages**, select **Deploy from a branch**, choose `main` and `/ (root)`, and save.
4. After deployment, visit `https://YOUR-USERNAME.github.io`.

## Edit

Edit text and links in `index.html`. Change colors, typography and layout in `styles.css`.

## Custom domain (optional)

Buy a domain separately and configure it under **Settings → Pages → Custom domain**. Follow GitHub's current DNS instructions for your registrar. GitHub Pages hosting itself is free for a public repository.

## Migration notes

- The existing Wix blog is linked rather than copied; its full article text and images have not been imported.
- The Wix contact form is replaced with an email link, since static GitHub Pages cannot process form submissions by itself.
- CV/resume download links and portrait photos were not imported. Add locally owned images and PDFs to the repository and link them from `index.html` when ready.
- Check publication details, links and biographical text before publishing.
